# Konkordanser
App for å finne konkordanser ImagiNation korpus

[![View on GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-blue?logo=github)](https://yoonsen.github.io/imag-konk-pwa/)

## Sokemuligheter

- Vanlig sok: `ord` eller `ord ord`
- Wildcard: `ord*`
- Termgrupper (kort): `[spise, spiser] middag`
- Termgrupper (JSON): `[["spise","spiser"],["middag"]]`
- Korpusfiltre: verktoy-ikonet i topplinja
- Sokeparametre: sliders-ikonet i topplinja

Tips: bruk sporsmalstegn-knappen i appen for en kort hjelpetekst.
