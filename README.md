# ImagiNation korpusutforsker

Studentrettet app for konkordanser, tellinger og trender i ImagiNation-korpuset.

[![View on GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-blue?logo=github)](https://yoonsen.github.io/imag-konk-pwa/)

## Søkemuligheter

- Vanlig søk: `ord` eller `ord ord`
- Wildcard: `ord*`
- OR-gruppe: `[spise, spiser] middag`
- Sammenligning i Telling og Trend: `{spise middag; sove middag}`
- Termgrupper (JSON): `[["spise","spiser"],["middag"]]`
- Korpusfiltre og søkeparametre åpnes fra panelet til venstre.

Tips: bruk spørsmålstegn-knappen i appen for en kort hjelpetekst.

## Versjoner

Appen følger Semantic Versioning. Utgitt versjon og kort Git-commit vises i
appen, slik at feilrapporter kan knyttes til den nøyaktige koden som kjørte.
Se [CHANGELOG.md](CHANGELOG.md) for endringer mellom versjoner.
